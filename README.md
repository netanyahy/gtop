## Установка

```sh
git clone https://github.com/<ваш-юзернейм>/gtop.git
cd gtop
./install.sh
```

Скрипт кладёт `gtop` в `/usr/local/bin` (сам вызовет `sudo` или `doas`, если нужны права). После этого запускай из любого места:

```sh
gtop            # цветная тема
gtop --gray     # серая тема (переключение на лету: клавиша g)
sudo gtop       # чтобы можно было убивать чужие процессы
```

Другие варианты установки:

| Команда | Куда ставит |
|---|---|
| `./install.sh` | `/usr/local/bin` |
| `./install.sh --user` | `~/.local/bin` (без root) |
| `./install.sh --prefix /opt/gtop` | `/opt/gtop/bin` |
| `./install.sh --uninstall` | удаляет установленный gtop |

Если файл `gtop` с таким именем уже есть и это не наш (например, другой `gtop` из npm), установщик ничего не перезапишет без `--force`.

**Обновление:** `git pull && ./install.sh`

## Клавиши

| Клавиша | Действие |
|---|---|
| `↑ ↓ PgUp PgDn Home End` | выбор процесса |
| `k` / `Del` / `F9` | послать сигнал (меню) |
| `K` | то же, сразу с выбранным SIGKILL |
| `/` | фильтр по имени, команде, пользователю или PID |
| `s` | сменить колонку сортировки |
| `c` `m` `p` `n` | сортировка по CPU / MEM / PID / имени |
| `r` | обратный порядок |
| `t` | дерево процессов |
| `g` | серая / цветная тема |
| `пробел` | пауза |
| `+` `-` | чаще / реже обновлять |
| `?` | помощь |
| `q` | выход |

Мышь: клик по строке, клик по заголовку колонки (сортировка), колесо.

## Требования

- Linux и Python 3.8+ с модулем `curses`.
  На Gentoo модуль включается флагом `USE=ncurses` у `dev-lang/python` (по умолчанию он включён).
- UTF-8 локаль: кольца рисуются символами Брайля. Проверить и выбрать: `eselect locale list`.
- Шрифт терминала с символами Брайля (подойдёт DejaVu Sans Mono или любой Nerd Font).
- Размер окна от 60x12, комфортно от 100x30. В низком окне нижний ряд панелей (сеть и диски) скрывается.

## Как это работает

- **CPU%**: из `/proc/stat`, `1 − Δidle/Δtotal` между замерами. Для процессов: `Δ(utime+stime) × ядра / Δtotal`, где 100% это одно ядро.
- **Кольца**: сетка из точек Брайля (2x4 на клетку), дуга 270° с градиентом зелёный → красный.
- **Графики**: площадные, на тех же точках Брайля, по два замера на клетку.
- **Kill**: `os.kill` с выбранным сигналом. PID 1 и самого себя программа не трогает.

Отладочный режим без curses, печатает один кадр в stdout: `gtop --snapshot 120x40`.
